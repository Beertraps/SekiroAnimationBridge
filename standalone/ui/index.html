    Your sources

    Folders the bridge reads game files from. Each one remembers its layout, game and your last selection; switch between them from the Import page.

    Game folder

    An unpacked game or a mod folder in the game’s own structure: chr, parts, mtd or material. Characters are listed at once; a character’s archives are read when you choose it.

    Collected folder

    Archives you copied together for one or a few characters, in any subfolders. Files that share a folder belong together.

    Custom layout

    For unusual setups: name the folders for animations, models, parts, textures and materials yourself, inside the source or anywhere else.

    Your tools

    What the bridge runs on this computer. Paths are remembered on this computer and shared with the command line.

    Tool locations

    The UI and the CLI use the same tools.

    DCX archives

    Built in through the conversion libraries.

    KRAK archives use your game’s Oodle library in place; it is never copied. DFLT needs no native library.

    Appearance

    Follow Windows, or keep one theme.

    Setup

    Release ZIPs set themselves up on the first start.

    Conversion libraries

    uv installs Python 3.13, Soulstruct and NumPy into the tool’s own environment. Run this to repeat or repair it.

    tools\setup_writer.cmd
    HKX decoder

    Included in release ZIPs. A source checkout builds it once; that needs Git and the .NET 9 SDK.

    tools\SekiroMotionDecoder\build_decoder.cmd

    Game packages

    Games from other engines, such as Devil May Cry 5, come as packages. FromSoftware games need none.

    Reading the packages…

    A package runs its own code on this computer. Install packages only from people you trust.

    Cache

    Unpacked animations, scans and skeleton previews in this tool’s work\asset-cache. Files that no source uses are removed when the bridge starts.

    Total
    Measuring…

    Your sources stay. A source you have removed, or a mod archive that has changed, leaves files behind until the next cleanup.

    Preview caching

    Clips are prepared in the background, so the next one shows at once.

    Retarget add-on

    Optional. Moves an animation from one character to another and adds animator controls inside Blender.

    Install it in Blender

    Edit › Preferences › Add-ons › Install from Disk, then choose the SekiroRetargetAssistant ZIP from this tool’s folder. Its tools are in the 3D Viewport sidebar under Retarget.

    Bake and export

    Match the bones, bake onto a character imported here, then use Export HKX in the add-on. It uses this bridge’s conversion Python and settings.

    Animate with controls

    The Control rig panel adds FK controls along the limbs and IK arms and legs with an IK/FK switch to a character imported here, with its animation baked onto them. Export works as before.
