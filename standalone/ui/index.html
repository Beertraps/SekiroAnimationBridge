DCX archive support

Built in through the conversion libraries. No Sekiro plugin required.

KRAK DCX uses your game’s Oodle library in place. DFLT needs no native library. The standalone DCX command can also compress a wrapper; animation export still produces a raw HKX for WitchyBND.

Setup

Release ZIPs set themselves up on the first start.

1. Conversion libraries

Prepared on the first start: uv downloads Python 3.13, Soulstruct and NumPy into the tool’s own environment. Run this to repeat or repair the setup.

tools\setup_writer.cmd
2. HKX decoder

Included in release ZIPs. A source checkout builds it once with this command, which requires Git and the .NET 9 SDK.

tools\SekiroMotionDecoder\build_decoder.cmd

The .cmd launchers handle PowerShell’s process execution policy. No machine-wide policy change is needed.

Retarget add-on

Optional. Moves an animation from one character to another inside Blender.

1. Install it in Blender

Edit › Preferences › Add-ons › Install from Disk, then choose the SekiroRetargetAssistant ZIP from this tool’s folder. Its tools are in the 3D Viewport sidebar under Retarget.

2. Bake and export

Match the bones, bake onto a character imported here, then use Export HKX in the add-on. It writes the HKX with this bridge’s conversion Python and settings. Starting this workspace lets the add-on find the bridge.
